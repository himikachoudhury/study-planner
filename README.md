# Study Planner Web App

A study planner web app built with HTML, CSS, and JavaScript.

## Features

* Add tasks
* Mark tasks complete
* Delete tasks
* Store tasks using localStorage
* Responsive layout
* Dark mode

## Technologies Used

* HTML
* CSS
* JavaScript

## Goals

This project is designed to improve:

* frontend development skills
* JavaScript fundamentals
* Git/GitHub workflow
* deployment experience

## Future Features

* Calendar integration
* Notifications
* User accounts
* AI study schedule generation
* Backend database
